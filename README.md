# 💡 AI Investor Style Quiz

An interactive AI-powered finance demo built for an AI Fair environment.

Users answer 10 quick behavioral questions, and the system analyzes their risk tolerance and investing mindset.  
Results are visualized with charts, a risk gauge, and a sample portfolio to make financial concepts easy to understand.

> Educational demo only — not financial advice.

## 🚀 Live Demo

## 🧠 Features

- Behavioral risk profiling
- Investor type classification
- Risk score gauge
- Portfolio visualization
- Explainable charts
- Demo Mode for live events
- Mobile-friendly UI

## 🎪 AI Fair Focus

This project was designed for:

- Multilingual student audiences
- Quick interaction (under 3 minutes)
- Visual learning
- Inclusive financial education

---

## ⚙️ How It Works

1. Scan the QR code
2. Answer 10 questions
3. The system scores each answer
4. A risk score is calculated
5. Charts and portfolio examples are generated
